# 生产分组与交接

完整阶段、版本接续、典型失败的退回方式及当前案件状态，以根目录 `AGENTS.md` 指向的[设计生产主流程](design-production-flow.md)和[续作状态](continuation-state.md)为准。本页补充分组、套准和导出实现细则；不能将工作流文字规则宣称为已实现的自动检测。

## 生成前的源素材预算与复用

- 先记录元素最大使用毫米尺寸、裁切比例与工艺，计算横纵均大于300PPI所需的有效原生像素。先核查所用工具能否实际输出，再调用；不能只在提示词中要求“高清”。
- 先查已有源素材、已锁定版本和同图跨盒面的复用情况。只改变位置、方向、工艺或排版时，复用原素材并同步工艺版，不重新生图。一次生成的合格素材应保存原文件、实际尺寸与对应工程；不能因同图使用多次而重复生成。
- 文字、标志、规则几何、流线和工艺边界优先使用可精修的矢量；复杂纹理保留达到预算的位图。工具达不到预算时先调整素材做法，不能反复生成同尺寸低清效果，也不能用插值或改DPI标签冒充细节恢复。
- 概念选款只确认方向；正式设计的母稿先通过实际尺寸素材检查，再从同一母稿和工艺版生成3D与客户文件。锁定源稿后不从带灯光的效果图反向重画。
- 工作台“方案确认范围”中，概念选款与生产母稿技术确认分开。后者必须通过当前素材技术检查；仍须另外完成视觉一致性、工艺、结构和工厂核验，不能据技术通过宣称可生产。

盒型/图层均以现有geomOf毫米坐标为准；盒内径不能冒充客户已确认外径。

1. 客户已制作的工艺PDF默认按源文件整版保留，同盒面、同一加工版中的多个图案不因路径分开而主动拆成独立素材，内部尺寸和相对位置保持不变。新设计的独立素材可按同盒面、同实际工艺版归组，默认整版操作；确需单独修改时再拆分。内部矢量路径仍保留，不压平成位图。普通印刷finish=none；金银、凸凹、UV等各自指定finish。factoryId取print/metal/film，plateId和plateName区分实际加工版；同工艺也可有多张版，不仅凭相同finish自动合并不同箔色、工序或源版。
2. 工艺覆盖印刷图案时，调用src/design/registration.js的bindRegistration建立同盒面关联，默认linked=true。独立烫印而没有印刷底图的元素无需伪造对应图案。不要手填猜测基准数值。
3. 图案默认等比缩放；按裁剪后剩余原生像素分别检查横纵PPI，都必须大于300。纯矢量源与位图区别判断，不能把SVG中的嵌入图片算成矢量。原生精度不够就重制或重新确定使用尺寸。
4. 生产PDF接入字体以src/export/productionFonts.js为准，目前内嵌本项目OFL思源黑体400/700、小薇明体400及Libre Baskerville700。新设计在预览与生产中使用同一字体文件；其他字体或字重需要先接入和核对，不能静默替换字体。字体子集未覆盖字符会在导出时拒绝。出血框与实际图案出血须分别检查，不能仅凭页面框确认不会裁切露白。
5. `node scripts/project-preflight.mjs drafts/工程.boxproj --production`读取真实源图尺寸并检查。失败时修改后复查。此命令不代替浏览器图像解码及导出后的PDF复核。
6. 提案deliveryMode=concept可评审工程；deliveryMode=production在生成提案、打开交接、工作台接收和生产导出时分别检查。两种模式都要客户确认具体视觉版本。保留A/B看图选款、实际来源调研和九板块理念说明，不用技术校样冒充真实设计案例。
7. 工作台“导出生产文件包”固定输出印刷层.pdf、工厂一工艺层.pdf、工厂二工艺层.pdf三份分层母版（没有可见素材也保留空白母版）、刀版参考SVG、交付说明和manifest.json。每份PDF内部按版与单独素材保留原生OCG图层，图稿保持矢量，位图保留原生精度；重新解析实际PDF检查图层、页面与图片PPI，并记录SHA-256。工艺母版默认全部可见，制版前须仅启用所需版，不能混版制版；编辑兼容性需工厂试开。角线仅编辑辅助，默认隐藏，不进入生产图案。
8. 检查完整盒子、单盒面细节、偏版与重新套准。3D是近似材质模拟，不能替代真实箔样、压力、温度、墨层、纸张成形与RIP审核；CMYK数值转换没有ICC/PDF-X认证。

SVG生产限制：文字先转成矢量轮廓；工艺SVG须为透明背景、白色正图（可用路径镂空），不能直接交付黑底反白图、彩色图或带样式/渐变/蒙版的复杂SVG。当前导出会拒绝这些文件，需先整理并核对工艺覆盖范围；不要将报错理解成自动完成了转换。

## 同源生产与放行门槛

- AI带灯光的盒体效果图仅作参考。正式确认使用实际尺寸平面母稿及其同源3D；复杂纹理允许合格原生位图，不强制简化成全矢量。请求高分辨率不代表实际拿到了高分辨率，读取实际输出并计算最终PPI。
- 已确认的工艺必须落实到工作台的实际元素、finish、factoryId、plateId及套准关联，不能只写说明。凝胶UV同盒面整版归组，块面填实、间隙镂空；边界不准保持待核样，不用“有一张SVG”冒充验收。
- 红灯表示已发现的技术错误，黄色表示未核验或工程已变更。技术通过不能证明设计一致。视觉/工艺/结构/工厂四项核验记录分别绑定当前工程内容指纹，修改素材、位置、尺寸、工艺、材质或参考基准后须复核。核验记录是人工凭据，不是不可伪造签名或自动认证。
- .boxproj备份和评审展示不受生产放行限制；工厂核样包必须通过技术预检，明确标记禁止量产，可先交工厂试开打样；正式生产包还须四项本版核验记录。不能先要求工厂试开通过却不给任何核样文件，也不能借核样模式绕过低精度。
