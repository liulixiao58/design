# 调研来源与两图选款

## 工作顺序

客户需求 → 分轮访谈补齐关键信息 → 包装 Skill 形成产品适配与设计假设 → 定向寻找专业案例并看图 → Skill 复审审美与应用可行性（未通过则调整任务重新采集，证据不足则补证）→ 合格元素在真实盒面比例上做小样并复审组合 → A/B 两套 45° 盒子展示图 → 客户看图选款/修改 → 深化同一设计的完整视觉系统和离线 HTML → 客户确认具体版本 → 同源独立图层进入工作台。

两套图采用同盒型、尺寸比例、背景和相近光线，至少能看到主展示面及侧面，清晰显示品牌、主图形、广告语与产品图位置。给出真实图片文件或直接展示，不用文字描述充当图片。需要原创位图时使用当前生图工具及相应 Skill。概念生图不等于可编辑工程；深化时核对盒面、图形、文字和工艺的一致性，无法还原的差异须明确说明。

## 每个项目的调研交付

使用场景是独立研究任务，按[工作流中的使用场景调研](prework-workflow.md#使用场景调研怎样做)执行：核实使用者/购买者/赠收关系、实际地点与动作、渠道及产品条件，保存图证和取舍。包装获奖案例只能支持视觉方法，不能单独证明使用习惯。设计前交付研究板和场景策划草案，选款及母稿确定后再生成四张场景，不能先画场景后补造研究依据。

- 先找同品类、同客群，再考虑相邻的家居、香氛、礼赠等类别；其他品类的元素说明适用理由，不机械照搬。
- 通常精选 3～5 个有实际图片可看的相关案例，覆盖至少两个可访问来源。数量不足说明具体缺口，不用不相关图片凑数。
- 每个案例记录标题、作者/品牌、日期或日期未知、原始链接、实际查看范围，并说明配色、字体、图形、工艺或构图中借鉴什么、如何应用。
- 优先查看近 12～24 个月作品，经典案例标清年份。以发布日期而非抓取日期判断新旧。
- 只有多个独立近期案例出现共同方向，或已阅读的可靠报告支持时，才称为趋势；单件作品只能称案例/灵感。未经统计不能称热门或最流行。
- 区分可浏览案例与可商用素材；参考设计方法并创作本案素材，不直接拿案例图片、商标或插画贴到客户包装上。
- 网站可访问不代表所有内容免费或持续可用。公开页面受限时换来源，需登录/订阅时告知缺口，不绕过限制。

## 研究放行检查

本次准备进入哪个设计步骤，先写清范围与必须解决的问题；已确认且未重开的决定沿用，不重复访谈或审批。完整新方向涉及的产品、受众、渠道、配色、字体等关键问题不能以缩小记录范围的方式隐去；有明确授权的局部研究则只放行对应小样。

在`drafts/<项目>-研究/研究记录.json`保存：

- `project`、`scope`：项目与本次允许推进的具体步骤。
- `questions`：每项含`id/question/conclusion/reviewed/sourceIds`；问题必须有明确结论，结论可为不采用，不能将“还未确定”写成已解决。
- `cases`：每项含`id/title/url/publishedAt/accessedAt/evidence/observed/interpretation/decision/reason/application`。`evidence`为相对JSON的本地看图证据；`publishedAt`查不到填“未知”。`observed`只写实际看到的现象；`interpretation`写设计推断。`decision`为“采用／淘汰／证据不足”；改造后采用须在`application`写明改造并经小样复审。证据不足的候选可保留在线索中，不能支撑已解决结论或设计选择。
- `choices`：每项含`element/sourceIds/application`，说明准备采用的方法及原创转化，必须指向已复审采用的案例。
- `limitations`：尚缺的资料、趋势结论或其他不在本次放行范围的决定；若影响当前步骤，则问题保持未解决，退回补证。

执行：

```text
node .agents/skills/alterlab-vcd-packaging/scripts/check-research.mjs drafts/<项目>-研究/研究记录.json
```

脚本核对记录、图片可解码和来源关联，生成同目录`研究板.html`与`研究检查.json`；失败时退出码为1。必须再打开研究板，核对图片内容与分析是否一致，把链接展示给设计师。脚本通过只能表述“研究资料完整、可复核”，不能替代审美、趋势或消费者验证，不能把人工填写的结论当独立模型评审。

客户上传的参考图使用`sourceType: customer`及`sourceNote`记录来源，不伪造公开链接。新提案JSON设置`researchRecord`为研究记录的相对路径，导出工具会重查并拦截不完整记录；旧项目不自动追认研究。该检查不代替已选款确认。

放行前逐项检查：实际看过原图且图证清晰；采用与淘汰均有具体理由（不强行为凑数制造淘汰项）；拟用元素可回溯；关键问题已解决；趋势判断有独立来源与时间依据。只有链接／文字、占位图、尚未复审或只有“高级、好看”的空泛理由均不算完成。

若不通过，按具体问题补图、补来源、修改方向或重新研究。每次修订后重跑；进入小样前复核，不能沿用过期检查结果。保持设计故事来自已使用的研究决定，不事后拼接大牌名称。

## 参考元素的审美与落地复审

这些标准指导 Codex 的视觉判断，不是独立审美模型或审美质量保证。必须实际看到图片，结合具体需求解释判断，不能用「高级」「有质感」「流行」代替证据，也不编造客观审美分数。

| 检查方面 | 要回答的问题 |
| --- | --- |
| 产品与品牌适配 | 图形、颜色和语义能否表达本产品的特点，符合受众、价格定位与场景？是否让人误认品类或暗示未经证实的功效？ |
| 色彩与材质 | 主辅色有无主次、对比是否足以阅读？金属反光是否遮盖文案？是否把场景灯光或摄影滤镜当成印刷颜色？ |
| 字体与信息层级 | 品牌、广告语、品类和辅助信息的阅读顺序是否清楚？中英文字形、字重、间距是否协调？参考的排版能否容纳客户的实际中文文案？ |
| 构图与图形 | 留白、疏密、比例、视觉重心和线条节奏是否有秩序？是否有一个清楚的主视觉，而非互相争抢的装饰？ |
| 全盒一致性 | 顶面、侧面、背面和转角能否形成同一套语言？产品照片、Logo、插画和四种工艺是否协调，而非分别好看但拼在一起失衡？ |
| 原创与辨识度 | 能否提取方法并重新创作？是否过度接近他人独有图形/标志？是否只是行业常见符号堆叠？ |
| 盒面与工艺应用 | 放到本案盒面、盖底遮挡与折边位置后是否仍成立？线条、字号与细节是否有打样条件？素材精度及授权是否满足预期用途？当前工作台是否能承载与编辑？ |

记录格式：`来源及实际看图范围｜候选元素｜与本产品的关系｜审美判断及可见依据｜拟用盒面/主辅角色｜原创改造方式｜工艺与软件边界｜决定及理由｜下一步`。

- **采用**：适配、审美和本次概念应用有依据，可进入小样；仍不等于已通过量产验证。
- **改造后采用**：说明具体改哪里，改造后复审再入选，不能将未完成修改视为通过。
- **淘汰**：给出具体不适用原因，将其转换为下一轮检索条件。
- **证据不足**：图片没看到、关键结构/授权/工艺依据不足等；先补证，不能替它判定通过。

将视觉参考与生产素材分开判断：无复制授权的第三方案例可用于研究构图方法，不能直接取其图片贴入客户包装。概念阶段尚无打样数据的工艺可作为待验证建议，但不能宣称生产可行。

通过后的局部小样至少检查：真实长宽比例、客户准确文字、产品原图、主视觉与工艺面积；重新看缩略图的阅读主次及近看的细节。不满足则修改组合或退回参考筛选，不能因为已收集足够数量而自动出方案。

例如 MOLONG：丝线的流动节奏可能适合表达包裹感，但应检查其是否与中文广告语争抢、在顶面是否显得空洞或杂乱、四工艺是否能分区。其他品类的强烈图形即使醒目，也必须证明适合蚕丝被和客户调性才能入选。这里仅示范判断方法，不代表未看图就已批准某项参考。
